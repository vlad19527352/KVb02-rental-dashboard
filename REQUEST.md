# Прокат · Бронирования с 1 по 24 ноября

Привет! К пятнице нужно сравнить ноябрьские брони по трём точкам выдачи. Я хочу сама выбирать даты и инвентарь, смотреть, сколько броней принесли деньги, и скачивать строки для сверки с администраторами. В выходные нагрузка сильно меняется, поэтому нужна панель, где ответы можно пересчитать под любой период.

Приложила `data/bookings.csv`. Это выгрузка по состоянию на 24 ноября. Кодировка UTF-8, разделитель запятая. Одна строка — одна бронь в её текущем состоянии. В поле с комментарием встречаются запятые внутри двойных кавычек.

| Поле | Что означает |
|---|---|
| `id` | Уникальный текстовый номер брони. |
| `date` | Дата проката в формате ГГГГ-ММ-ДД. По ней отбираем бронь и строим график. |
| `rental_point` | `ice_center` — Ледовый центр, `forest_base` — Лесная база, `north_slope` — Северный склон. |
| `activity` | `ski` — лыжи, `skate` — коньки, `snowboard` — сноуборды, `tube` — тюбинги. |
| `channel` | `site` — сайт, `desk` — стойка, `phone` — телефон. |
| `status` | `paid` — оплачено, `partially_refunded` — частичный возврат, `refunded` — полный возврат, `cancelled` — отменено до оплаты, `pending` — ждёт оплаты. |
| `quantity` | Количество единиц инвентаря в брони. Целое положительное число. |
| `amount`, `refund_amount` | Сколько получили и сколько вернули, оба значения в целых неотрицательных рублях. |
| `comment` | Служебное примечание, может быть пустым. |

По статусам нужна такая проверка. У оплаченной брони сумма больше нуля и возврат равен нулю. При частичном возврате вернули больше нуля и меньше суммы. При полном — вернули всю положительную сумму. У отменённой до оплаты и у ожидающей оплаты оба денежных поля равны нулю.

Хочу открыть страницу на своём компьютере и выбрать CSV. Оставь фильтры по датам, точке выдачи, инвентарю и статусу. Обе указанные даты входят в период. Все выставленные условия действуют вместе. Если фильтр пуст, по нему можно брать все значения.

Покажи четыре числа. «Брони в отборе» — все подходящие записи, в том числе отмены. «Брони с оплатой» — те, по которым после возврата осталась положительная оплата. «Чистая выручка» — сумма оплат за вычетом возвратов. «Возвраты» — сколько денег вернули по этим же броням. Всё считаем по дате проката. Движение денег по дате платежа или возврата потребует другой выгрузки.

Нужен график чистой выручки по дням и разбивка по инвентарю с количеством броней с оплатой и чистой выручкой. Ниже таблица броней с постраничным просмотром.

Нужны четыре отдельных CSV. Я буду отправлять их разным людям.

- **Брони.** Администраторам для сверки отдельных броней нужны все поля и все строки из отбора в исходном порядке, включая строки с других страниц таблицы.
- **Выручка по дням.** Для недельной записки нужна сводка по каждой дате проката, которая попала в отбор. Покажи число всех броней, число броней с оплатой, сколько получили, сколько вернули и сколько осталось.
- **Точки и инвентарь.** Для сравнения точек нужны те же показатели по каждой паре точки выдачи и вида инвентаря, которая попала в отбор.
- **Возвраты.** Для сверки с бухгалтерией отдай полные записи по броням из отбора, где есть возврат. Там должны быть и полные, и частичные возвраты.

Любой файл должен соответствовать фильтрам, которые я сейчас вижу на панели. На пустом отборе в каждом CSV нужны его заголовки.

Если по фильтрам ничего не подошло, покажи нули и сообщение. В скачанном CSV останутся заголовки. При ошибке загрузки файла (например, пропущен столбец, повторился ID или возврат больше оплаты) покажи причину, убери старые цифры и отключи скачивание, пока не загрузится корректный файл.
